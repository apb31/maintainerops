# Contributing

Contributions are welcome.

1. Open an issue describing the bug, maintenance need, or proposed improvement.
2. Keep changes focused and testable.
3. Add or update tests when behavior changes.
4. Run `python -m unittest discover -s tests -v`.
5. Open a pull request with a concise description of the change and how it was verified.

Maintainer decisions prioritize correctness, usefulness, maintainability, and backward compatibility.
